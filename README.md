# PyVista + PySide6 Examples

Коллекция простых примеров и шаблонов для интеграции интерактивной 3D-визуализации **PyVista** в графические интерфейсы на **PySide6 (Qt)**.

## 🚀 Быстрый старт

Нужен только [**uv**](https://docs.astral.sh/uv/) — он сам подтянет Python и зависимости.

Установка зависимостей:
```bash
uv sync
```

Запуск примера:
```bash
uv run 01_basic_window.py
```

## 📂 Структура репозитория
* `01_basic_window.py` — Минимальный шаблон: встраивание плоттера в окно PySide6 с кнопкой управления.
* `02_matplotlib_multi.py` — Сетка из нескольких графиков Matplotlib в окне PySide6.
* `03_matplotlib_pcolormesh.py` — Варианты `pcolormesh`: прямоугольная, искажённая и полярная сетки.
* `04_pyvista_pcolormesh_3d.py` — Те же три сетки как 3D-поверхности в PyVista (три `QtInteractor`).
* `05_pyvista_voxels_3d.py` — 3D-объёмные данные: воксели (threshold) против срезов и изоповерхностей (`-n/--size`).
* `06_advanced_3d_fields.py` — Продвинутые методы: объёмный рендеринг (volume) и скалярные глифы (`-n/--size`).
* `07_interactive_volume.py` — Интерактивный volume rendering: смена палитры и размера сетки через ползунок/комбобокс.
* `08_volume_functions.py` — Генератор 3D-полей высокого разрешения: выбор функции поля и палитры, ползунок разрешения.
* `09_volume_opacity_control.py` — Управление прозрачностью volume ползунком + кэш сетки (без пересчёта NumPy).
* `10_quantum_orbitals.py` — Квантовые орбитали водорода (n, l, m): объёмный рендеринг |Ψ|², палитра и прозрачность.

### Размер сетки
Примеры `05` и `06` принимают размер сетки одним значением на все три измерения (`-n/--size`, по умолчанию 40 и 25):
```bash
uv run 05_pyvista_voxels_3d.py -n 80
uv run 06_advanced_3d_fields.py -n 40
```

## ⚠️ Важно знать
При закрытии окон Qt всегда вызывайте метод `plotter.close()` внутри события `closeEvent`, чтобы корректно завершать процессы VTK и избегать зависания приложения.
