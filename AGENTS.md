# AGENTS.md

Правила для AI-агентов, работающих с **pyvista-gui-labs**.

1. **Не менять код без одобрения идеи человеком.** Сначала описать изменение
   (что, зачем, какие файлы, риски) и дождаться явного «да». Мелкие правки
   этой памятки под правило не попадают.
2. **Каждый коммит подписывать суффиксом** `[<agent name>/<model name>]` в конце
   сообщения, например: `feat: add PolarGrid [pi/deepseek-v4.1-flash]`.
   Подставлять свои имя и модель, не хардкодить чужие.
